# TFG_Amestoy_2026
Correlation analysis between pipolins and other bacterial genes and MGEs
## Final Bachelor’s Thesis
## Author: Jorge Fernández Amestoy
## Directors: Modesto Redrejo Rodríguez & Victor Mateo Cáceres
This repository contains scripts used in my final bachelor's thesis. 
The project is based on the premise that the presence of pipolins might be influenced by the co-occurrence of other MGEs or genes within the same bacterial genome. 
The primary objective is to identify genes significantly associated with piPolB—serving as a marker for pipolins—and to analyze the role of MGEs in these associations.

The analysis is divided into two sub-analyses:
  1. An initial analysis covering approximately 2.8 million bacterial genomes from GenBank (bacteria_analysis).
  2. A second, more specific analysis covering approximately 32,000 *Escherichia coli* genomes (ecoli_analysis).

Each script includes a brief description of its function and, where applicable, details on particularly relevant parameters.
